    ☁️ Cloud sync via GitHub Gist

    Sync all your projects across every device — phone, tablet, computer. Uses a Gist in your free GitHub account. The Gist is secret, not private: it is unlisted, but anyone who has its link can open it without signing in. Treat the Gist ID like a password and never share it.

    One-time setup: Go to github.com/settings/tokens/new → Note: "Reno Master" → Expiration: 90 days or less (renew it when it expires; do not choose "No expiration") → tick gist scope only → Generate → copy the token below.
